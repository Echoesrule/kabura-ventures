# 7. BOOKING STATUS FLOW

```
User Books Tour
    ↓
[Pending] (awaiting admin confirmation)
    ↓ (admin confirms)
[Confirmed] (booking confirmed)
    ↓
[Deposit Paid] (customer pays deposit)
    ↓
[Completed] (trip completed)

OR ─→ [Cancelled]

OR ─→ [No-show]
```

## Status Legend
| Status | Meaning |
|--------|---------|
| **Pending** | Booking received, awaiting admin approval |
| **Confirmed** | Admin approved, customer can pay deposit |
| **Deposit Paid** | Partial payment received |
| **Completed** | Trip finished successfully |
| **Cancelled** | Booking cancelled by user or admin |
| **No-show** | Customer didn't show up for trip |
